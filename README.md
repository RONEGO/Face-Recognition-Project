## О проекте

Мы разрабатываем пайплайн распознавания лиц: на вход подаётся фотография, на выходе получается вектор-эмбеддинг лица, по которому можно определить, кто изображён на снимке.

Пример практического применения — система доступа в офис: сотрудник проходит через турникет по лицу, а не по пропуску. Ту же систему можно использовать для обеспечения безопасности в помещениях.

Проект исследовательский. Основная работа — чтение статей, разбор архитектур нейросетей и постановка экспериментов, а не только сборка готовых решений.

```
фото → detection → alignment → recognition → эмбеддинг
```

## Особенности проекта

- **Исследования.** Разбираем статьи по face recognition, воспроизводим описанные подходы и проверяем их в экспериментах.
- **Специальные лосс-функции.** Сами реализуем Triplet Loss и ArcFace Loss и сравниваем, как они влияют на качество эмбеддингов. В первую очередь упор делаем именно на этап recognition.
- **Свои модели на каждом этапе.** Обучаем отдельные сети для детекции лица, выравнивания по ключевым точкам и получения эмбеддинга.
- **Сравнение с готовыми решениями.** Берём существующие open-source модели, пробуем их улучшить и считаем мини-бенчмарки.
- **Данные.** Используем открытые датасеты (LFW, CASIA-WebFace, CelebA) и дополняем их собственными размеченными фотографиями.

## План

1. **Обзор литературы.** Разбираемся, как устроены современные системы распознавания лиц.
2. **Данные.** Собираем и готовим датасеты, добавляем свои фотографии.
3. **Face detection.** Обучаем модель, которая находит лица на фото.
4. **Face alignment.** Обучаем модель, которая выравнивает лицо по ключевым точкам.
5. **Face recognition.** Обучаем модель, которая строит эмбеддинги, и реализуем Triplet Loss и ArcFace Loss.
6. **Пайплайн.** Объединяем detection → alignment → recognition в одну систему.
7. **Бенчмарки.** Сравниваем наши модели с готовыми решениями и пробуем их улучшить.
8. **Сервис.** Делаем сервис для работы с изображениями.
9. **Дополнительно.** Адаптируем пайплайн и сервис под видео в реальном времени.
